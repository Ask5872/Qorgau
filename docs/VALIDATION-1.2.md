# Проверка Qorgau 1.2

Дата подготовки: 4 октября 2026. Стенд сборки — Linux x86-64, Python 3.12, CPU. Физическая веб-камера, Windows hook, WebView2 и переключение рабочих столов здесь недоступны. Проверки логики с подменёнными Win32-вызовами не подтверждают работу Windows-защиты на реальном компьютере.

## Итоговый прогон новой сборки

**Итог: 93 теста прошли, ошибок и пропусков нет** (`test-results-1.2.xml`). Прогон включает загрузку настоящих моделей из ASCII-пути и пути с кириллицей, геометрию и историю положения телефона, камеру с отдельными потоками захвата/анализа, порядок событий до отстранения, освобождение ресурсов при отказе защиты, PIN-разблокировку и имитацию жизненного цикла Win32/WebView2. Одно предупреждение относится к устаревающему HTTPX-адаптеру TestClient, не к работе приложения.

Проверка интерфейса в jsdom с настоящим локальным HTTP API прошла: сохранение экзамена, серверное время, старт, ответ, непрерывный MJPEG-поток, автоматическое отстранение и повторная авторизация по PIN (`ui-flow-1.2.json`). Камера и признак изоляции в этом сценарии подменены. Отдельная DOM-проверка подтвердила heartbeat до старта, запрет ухода из теста, блокировку внешних ссылок и window.open, аварийную кнопку, честные подписи телефона и экран разблокировки.

Python-файлы компилируются, JavaScript проходит проверку синтаксиса. Полноценный браузерный рендеринг, физическая веб-камера и нативный Windows на этом стенде не проверены. Результаты 1.1 из `VALIDATION.md` и `test-results-1.1.xml` относятся только к предыдущей сборке.

## Что проверяется в изменениях 1.2

- Один неподвижный телефон высоко в кадре не должен считаться наблюдаемым подъёмом; подъём требует последовательного движения одного объекта вверх.
- Потеря объекта, большой разрыв кадров и повторный кадр не должны продолжать прежнюю историю движения или удержания.
- Для возможного наведения нужны пригодный контур и плоскость, положение в кадре и удержание не менее 0,35 секунды на трёх разных кадрах. Слишком маленький, узкий или закрытый контур не даёт доказательства направления.
- Подтверждённые события подъёма и возможного наведения должны записываться до автоматического прекращения попытки. Условие остановки телефона остаётся самостоятельным: от 1,5 секунды, confidence от 0,65, минимум три разных свежих кадра.
- Ни один результат анализа не утверждает доказанную фотографию, известную сторону объектива или нажатие кнопки камеры телефона.
- Обычный рабочий стол должен восстанавливаться до завершения собственного дочернего процесса при аварийном выходе, потере сигнала интерфейса и сбое оболочки.
- Ошибка подготовки окна, регистрации аварийного сочетания или переключения рабочего стола не должна оставлять пользователя в недоступном окружении.
- Во время активного экзамена переходы из страницы теста и новые окна блокируются, ответы и таймер продолжают работать. После завершения доступны преподаватель и отчёты.
- На Windows настоящий старт из браузера или оболочки без изоляции отклоняется с указанием основного запуска.

Автоматические проверки не заменяют ручные пункты ниже и не измеряют точность на студентах. Геометрический признак плоскости телефона — наблюдение возможного положения, а не проверка приложения камеры.

## Ручная матрица на целевом Windows-компьютере

Проводить с тестовым экзаменом и добровольным участником до использования для значимых оценок. Начать с проверки выхода без активного экзамена. Записать версию Windows, Python, модель камеры, разрешение, FPS видео и FPS анализа.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Обновление прежней папки с сохранением `.venv` и `data` | Прежний PIN, экзамен и отчёты доступны; установщик проверяет модели |
| Первый `02_start.cmd` без прежних данных | PIN виден в отдельном окне до перехода; после подтверждения открывается Qorgau на отдельном рабочем столе |
| `Ctrl+Shift+Q` до начала экзамена | Возвращается обычный рабочий стол; окно Qorgau завершается; чужие программы остаются открытыми |
| Ошибка запуска оболочки / отсутствующий WebView2 | Понятная ошибка; обычный рабочий стол сохраняется или восстанавливается; нет бесконечного ожидания |
| Включение камеры при хорошем свете | Видео и анализ готовы; записаны фактические FPS и разрешение |
| Камера занята или отключена | Понятная ошибка; экзамен не начинается по старому изображению |
| Сохранение собственных вопросов, калибровка и старт | Преподаватель задаёт время; варианты перемешаны; участник не видит ключи ответов |
| Alt+Tab, Win, PrtScn, Ctrl+C/V, Ctrl+Tab, Ctrl+PageUp/PageDown | Ограничение действует в изолированной оболочке; попытки отражаются в журнале |
| Открытые заранее браузер и другая программа | Их окна остаются на обычном рабочем столе; из теста к ним нельзя перейти обычными сочетаниями |
| Ссылка, новое окно, навигация «назад» во время теста | Участник остаётся на странице экзамена; ответы не теряются |
| `Ctrl+Shift+Q` во время экзамена | Обычный рабочий стол возвращается, попытка прервана, отправленные ответы сохраняются |
| Контролируемое зависание интерфейса | После более 15 секунд без его сигнала обычный рабочий стол возвращается; завершается только дочерняя оболочка Qorgau |
| Ctrl+Alt+Delete | Защищённый системный экран остаётся доступным; приложение не заявляет его блокировку |
| Неподвижный телефон уже высоко в кадре | Возможна обычная детекция; наблюдаемый подъём без движения не заявляется |
| Телефон плавно поднимается из нижней части кадра | При отслеживаемом объекте появляется событие подъёма |
| Телефон крупно удерживается плоскостью к веб-камере | При видимом контуре появляется возможное наведение; надпись не утверждает факт съёмки |
| Телефон боком, частично скрыт рукой, в разных чехлах | Записать пропуски и ложные признаки; неизвестное положение не считается доказательством отсутствия телефона |
| Телефон уверенно виден 2–3 секунды | Попытка прекращается по правилу телефона; уже записанные признаки и ответы сохранены |
| Телефон на один короткий момент | Нет немедленного отстранения по единственному кадру |
| Похожие предметы и обычное чтение вопросов | Измерить ложные события и остановки; не объявлять точность без выборки |
| Перезапуск после отстранения | Новый экзамен всё ещё заблокирован; преподаватель по PIN может разрешить отдельную новую попытку |
| Обычное завершение и экспорт отчёта | Ответы и итог сохранены; преподаватель может выгрузить JSON/CSV/HTML |
| `05_start_browser.cmd` на Windows | Камера доступна для диагностики; настоящий старт направляет к `02_start.cmd` |
| Закрытие приложения после завершения | Исходный рабочий стол возвращается; следующие приложения и камера работают обычным образом |
| Работа без интернета после установки | Основные сценарии используют локальные модели и данные |

## Что нельзя заключить из этих проверок

Нельзя заявлять подтверждённое нажатие кнопки съёмки постороннего телефона, точку взгляда с высокой точностью, полную защиту ОС, блокировку всех способов записи экрана или обходов администратора. Отдельно нужны измерения пропусков и ложных отстранений на разных телефонах, участниках, освещении и камерах. Скорость синтетического источника версии 1.1 не является гарантией FPS физической веб-камеры в Windows.
