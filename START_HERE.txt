QORGAU 1.9.7 — РЕАЛЬНЫЙ ЛОКАЛЬНЫЙ ЭКЗАМЕН

ЕСЛИ ПРИЛОЖЕНИЕ УЖЕ УСТАНОВЛЕНО
1. Закройте Qorgau и окно его запуска. Если старая версия удерживает
   рабочий стол, нажмите Ctrl+Shift+Q, затем закройте оставшееся окно.
2. Распакуйте новый ZIP через «Извлечь всё».
3. Содержимое новой папки Qorgau скопируйте в прежнюю папку
   Qorgau с заменой файлов. Сохраните папки .venv и data:
   в них библиотеки, PIN и прежние результаты.
4. Запустите 01_install.cmd для проверки обновления.
5. Откройте 02_start.cmd из обновлённой папки. Заголовок должен быть
   «Qorgau 1.9.7 — кабинеты». Если номера 1.9.7 нет, открыта другая версия.

ЕСЛИ ЭТО ПЕРВАЯ УСТАНОВКА
1. Установите Python 3.12 x64 с python.org, включите Add Python to PATH.
2. Нажмите правой кнопкой по ZIP — «Извлечь всё».
3. В распакованной папке Qorgau запустите 01_install.cmd.
   Рядом должны быть requirements.txt, run.py и папки проекта.
   Интернет нужен один раз для установки библиотек.

Экзамен проходит на компьютере или ноутбуке с веб-камерой.
Телефон — постороннее устройство; подключать его не требуется.

ПРОВЕСТИ НАСТОЯЩИЙ ЭКЗАМЕН
1. Запустите 02_start.cmd. Откроется обычное окно Qorgau.
   Не закрывайте окно консоли.
2. При первом запуске запишите PIN из отдельного окна.
   При обновлении используется прежний PIN.
3. Выберите «Вход преподавателя», войдите по PIN,
   откройте «Редактор теста».
   Укажите название, время и свои вопросы;
   в каждом вопросе четыре варианта и один правильный ответ.
   Нажмите «Сохранить экзамен», затем «Передать участнику».
   Доступ преподавателя закроется, откроется форма входа участника.
4. Участник заполняет имя и группу, затем входит в свой кабинет.
   Включите «Камера», дождитесь видео и готовности анализа.
   В кадре должно быть одно хорошо освещённое лицо.
5. Калибровку можно пройти, остановить на любой точке или пропустить.
   Если начали, смотрите на чёрную точку. Всего пять точек.
   Кнопка «Продолжить с тем, что есть» сохраняет принятые измерения
   и открывает начало теста. После ошибки нажмите «Перейти к экзамену».
   Esc также закрывает мастер с сохранением готовых точек.
   Перед стартом видно, какой контроль доступен. Неполная настройка
   не считается точным контролем взгляда и не мешает сдавать экзамен.
6. Нажмите «Начать экзамен», подтвердите условия обработки,
   затем нажмите «Начать тест». Имя и группа уже заполнены при входе.
   Только теперь откроется защищённое полноэкранное окно теста
   на отдельном рабочем столе Windows и включится блокировка клавиш.
7. После завершения теста обычный рабочий стол вернётся автоматически.
   В прежнем окне Qorgau участник увидит результат и сможет нажать
   «Завершить работу». Следующий участник входит по имени и группе;
   для просмотра отчётов преподаватель входит по PIN в свой кабинет.
   Перезапуск приложения между участниками не нужен.

ЗАЩИТА ВКЛЮЧАЕТСЯ ТОЛЬКО НА ВРЕМЯ ТЕСТА
На экранах входа, в кабинете преподавателя и при подготовке участника
можно свернуть окно, пользоваться Alt+Tab, Win, копированием и вставкой.
Камера и калибровка сами по себе не блокируют рабочий стол.
Ограничения снимаются после сдачи теста, истечения времени, остановки
по телефону, взгляду или голове либо технического прерывания. Результат и уже отправленные
ответы остаются в основном окне и отчёте.
Оформление остаётся белым, чёрным и серым; два входа разделены.
В главном окне доступны системные кнопки Windows и дополнительные
«−» (свернуть) / «×» (закрыть) в правом верхнем углу.
Размер окна автоматически помещается в рабочую область экрана.
Если содержимого много, используйте вертикальную прокрутку.

СТРОГИЕ ПРАВИЛА ПРЕКРАЩЕНИЯ ПОПЫТКИ
Телефон: первое пригодное распознавание с confidence модели ≥ 0,40
на одном свежем кадре. Дополнительной задержки и порога площади нет.
Кусочек телефона сработает, если модель распознала его как телефон;
узнавание произвольно маленького фрагмента не гарантируется.
Взгляд — только при полной проверенной калибровке. Минимум три
последовательных пригодных измерения подтверждают
выход за одну и ту же сторону экрана с учётом погрешности калибровки.
Подтверждение занимает не менее 0,25 с; при низком FPS — дольше.
Одиночный скачок или неуверенная оценка у края тест не прекращает.
Голова — только при сохранённой центральной точке: первое пригодное
отклонение более 5° по любой из трёх осей
от центрального положения калибровки, в том числе при моргании.
Правила обязательны, пороги подтверждения в редакторе не изменяются.
Реакция зависит от поступления кадра и скорости анализа камеры.
Уже отправленные ответы, баллы и причина остановки сохраняются.
Новый экзамен заблокирован даже после перезапуска приложения.
Преподаватель проверяет событие, входит по PIN и нажимает
«Разрешить новую попытку». Предыдущий отчёт остаётся.
Срабатывание правила не является доказательством списывания.

ПОДНЯТИЕ И НАВЕДЕНИЕ
Система отмечает движение телефона вверх и возможное наведение
по контуру, положению и устойчивому удержанию. Последовательность
подъёма и удержания того же телефона рядом с лицом отмечается как
«Признаки возможной съёмки». Сторона объектива, нажатие кнопки
съёмки и факт фотографии не подтверждаются. Для остановки достаточно
первого пригодного распознавания телефона по правилу выше.
Поэтому остановка может наступить раньше подъёма или наведения.

КНИГИ, УСТРОЙСТВА И ЛИСТЫ
YOLO также ищет книги, ноутбуки и телевизоры/мониторы.
Отдельный алгоритм отмечает возможный лист с текстом по форме
и текстуре. Он не читает текст и не определяет шпаргалки достоверно.
Эти эпизоды появляются в журнале для проверки преподавателем
и НЕ прекращают экзамен автоматически. Модели уже в архиве;
установщик проверит модели и обновит зависимости.
Снимки сохраняются только при отдельном согласии участника.

КАЛИБРОВКА, ВЗГЛЯД, ГОЛОВА И ЛИЦА
Калибровка содержит до пяти точек и не обязательна для старта.
Полная настройка включает подтверждение взгляда. При частичной
настройке приблизительный взгляд используется только для наблюдения.
Голова контролируется только при наличии пригодной исходной позы.
Если ни одной точки нет, экзамен всё равно доступен: работают телефон,
наблюдение лиц и защита окна при доступной камере.
Режим записывается в отчёт преподавателя.

КАМЕРА
Видео и анализ работают отдельно. FPS видео, FPS анализа
и фактическое разрешение доступны в диагностике /api/state. Приложение запрашивает
720p / 30 кадров/с, целевой показ — 24 FPS; скорость зависит
от камеры и ноутбука, это не гарантированные значения.

ЗАПУСКИ
02_start.cmd — обычное окно; изоляция Windows только на время теста.
03_exam_windows.cmd — прежнее имя запуска реального режима.
05_start_browser.cmd — диагностика камеры в браузере;
                       настоящий экзамен на Windows закрыт.
04_reset_pin.cmd — новый PIN, если прежний забыт.
02_demo.cmd — просмотр теста без настоящей камеры и защиты Windows.
Qorgau-Preview.html — только демонстрация, без камеры, PIN 2026.
Закрывайте предыдущий запуск перед открытием другого.

АВАРИЙНЫЙ ВЫХОД ВО ВРЕМЯ ТЕСТА: Ctrl+Shift+Q.
Для каждой защищённой попытки работает независимый процесс наблюдения.
Он сначала возвращает обычный рабочий стол, затем завершает только
экзаменационное окно, даже если оно перестало отвечать. Активная
попытка прерывается, основное окно Qorgau остаётся открытым.
Вне теста это сочетание приложением не захватывается.
При потере сигнала экзаменационного окна более 15 секунд рабочий стол
возвращается автоматически. Чужие приложения не закрываются.
